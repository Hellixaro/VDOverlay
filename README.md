## VD Overlay
An easy to use overlay to easily understand clock callouts for different VD maps.

Insert: Lock/Unlock map
F9/F10: Swap between maps, F9 for previous and F10 for next
±/↑↓: Resize the map

You can change all maps yourself inside the created folder ViolenceDistrictOverlay inside AppData/Roaming (%appdata%\ViolenceDistrictOverlay)
